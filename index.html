2. DATOS QUE RECOPILAMOS Y FINALIDAD

A. Datos facilitados voluntariamente (Contacto)

  • Dirección de correo electrónico y mensaje: Si utilizas la sección o formulario de contacto, recopilamos tu email y el contenido enviado para responder a tus consultas o incidencias.
  • Diagnóstico técnico adjunto: Para resolver problemas de compatibilidad o fallos en el servicio, la aplicación puede adjuntar automáticamente datos técnicos de tu dispositivo (marca, modelo, versión de Android, versión de la app, arquitectura, tipo de conexión, nivel de batería y estado del GPS).

B. Datos técnicos y de uso procesados automáticamente

  • Identificador de instalación (UUID): Tras la instalación de la app, se genera un código único anónimo que se transmite en las cabeceras de las peticiones HTTP/HTTPS para procesar correctamente las solicitudes del servidor sin vincularlas a tu identidad personal.
  • Logs de auditoría y dirección IP: Cada vez que realizas una consulta dentro de la app, nuestros servidores registran automáticamente la dirección IP de origen, ruta solicitada, tipo de cliente (User-Agent), fecha/hora y código de estado con fines de seguridad y prevención de fraudes o ataques.

C. Ubicación precisa (GPS)

  • Localización en tiempo real: Solo si otorgas explícitamente el permiso de GPS en tu dispositivo Android, la aplicación accederá a tu ubicación para situarte en el mapa y mostrarte monumentos cercanos. Estos datos de ubicación en tiempo real no se almacenan en el historial de nuestros servidores.

D. Preferencias del usuario (Almacenamiento local)

  • Tus ciudades favoritas y búsquedas recientes se guardan de forma exclusiva en el almacenamiento local del propio dispositivo (DataStore) y nunca son transmitidas a nuestros servidores.

3. BASE LEGAL PARA EL TRATAMIENTO (RGPD)

Procesamos tus datos de acuerdo con el Reglamento General de Protección de Datos (RGPD) de la UE bajo las siguientes bases legales:

  • Consentimiento: Al otorgar permisos explícitos de ubicación GPS o al enviar una consulta a través del formulario de contacto.
  • Interés legítimo: Para garantizar la seguridad, estabilidad e integridad del backend API mediante registros de auditoría y solucionar problemas técnicos.

4. CONSERVACIÓN DE DATOS

No utilizamos cookies publicitarias de terceros ni rastreadores comerciales. Los mensajes recibidos mediante contacto y los registros de seguridad del servidor se conservan únicamente durante el tiempo estrictamente necesario para resolver la consulta o garantizar la integridad del servicio.

5. SEGURIDAD Y TRANSFERENCIA DE DATOS

No vendemos, alquilamos ni transferimos tus datos personales o dirección de correo a terceros. Toda la comunicación entre la aplicación móvil Segento y nuestro servidor API backend se transmite de forma cifrada mediante protocolos seguros HTTPS (TLS/SSL).

6. DERECHOS DEL USUARIO (DERECHOS ARCO)

Como usuario residente en el Espacio Económico Europeo (EEE), tienes derecho a:

  • Acceder, rectificar o solicitar la eliminación de los datos personales facilitados mediante el contacto.
  • Retirar tu consentimiento en cualquier momento (por ejemplo, revocando los permisos de ubicación GPS o desinstalando la aplicación).

Para ejercer cualquiera de tus derechos, puedes escribirnos directamente a segentotravel@gmail.com. Responderemos a tu solicitud en un plazo máximo de 30 días.
